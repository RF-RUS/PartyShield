# Чеклист очистки PartyShield

## Удаление из репозитория (Git)

- [x] `out/` — статический билд (уже в .gitignore)
- [x] `remnashop-cabinet-main/` — посторонний проект (уже исключён из tsconfig)
- [ ] `.next/` — кэш сборки (уже в .gitignore)

## Удаление с хостинга (public_html)

### Что удалить перед новой выкладкой:

- [ ] Старые HTML-файлы в корне `public_html/` (index.html, pricing.html и т.д.)
- [ ] Старые папки маршрутов (`/pricing/`, `/try/`, `/support/` и т.д.)
- [ ] Старая папка `_next/`
- [ ] Временные файлы: `*.tmp`, `*.bak`, `*.log`
- [ ] Архивы: `*.zip`, `*.tar.gz`
- [ ] Файлы от предыдущих проектов (composer.json, wp-config.php и т.д.)

### Что НЕ удалять:

- [ ] Папку `.well-known/` — нужна для SSL-верификации
- [ ] Папку `cgi-bin/` — если используется хостингом

## Проверка после очистки

- [ ] В `public_html/` нет файлов, не относящихся к PartyShield
- [ ] Нет дублирующихся папок (две `_next/`, две `pricing/`)
- [ ] Нет файлов с правами 777

## Проверка деплоя

- [ ] `https://partyshield.space` открывается
- [ ] Все страницы работают (/, /pricing/, /try/, /support/, /privacy/, /refer/)
- [ ] SSL-сертификат активен
- [ ] Переключение языков работает (RU ↔ EN)
- [ ] Мобильная версия корректна
- [ ] Нет 404 на внутренних ссылках
- [ ] `.htaccess` работает (HTTPS-редирект, кэширование)
