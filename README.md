# PartyShield - VPN Service Website

Современный многостраничный сайт для VPN-сервиса PartyShield с поддержкой русского и английского языков. Собирается как статический сайт (`next export`) и может размещаться на любом статическом хостинге.

## Технологии

- **Next.js 14** - React фреймворк с App Router (статический экспорт, `output: 'export'`)
- **TypeScript** - типизация
- **Tailwind CSS** - стилизация
- **CSS-анимации** - плавные переходы (см. `app/globals.css`)
- **Lucide React** - иконки

## Структура проекта

```
PartyShield/
├── app/
│   ├── page.tsx              # Главная страница
│   ├── pricing/
│   │   ├── page.tsx          # Метаданные (server)
│   │   └── PricingContent.tsx# UI тарифов (client)
│   ├── try/                  # Страница "Попробовать"
│   ├── support/              # Страница поддержки (видео + FAQ)
│   ├── refer/                # Реферальная программа
│   ├── privacy/              # Политика конфиденциальности
│   ├── terms/                # Пользовательское соглашение
│   ├── layout.tsx            # Корневой layout + метаданные
│   └── globals.css           # Глобальные стили и анимации
├── components/
│   ├── Header.tsx            # Шапка сайта
│   ├── Footer.tsx            # Подвал сайта
│   ├── Logo.tsx              # Логотип (переиспользуется)
│   └── LanguageToggle.tsx    # Переключатель языка
├── contexts/
│   └── LanguageContext.tsx   # Контекст для переключения языков
├── lib/
│   ├── i18n.ts               # Переводы (русский/английский)
│   └── constants.ts          # Ссылки и константы
└── package.json
```

Каждая внутренняя страница разделена на серверный `page.tsx` (экспортирует уникальные `metadata` для SEO) и клиентский `*Content.tsx` (интерактивный UI, использует контекст языка).

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите dev-сервер:
```bash
npm run dev
```

3. Откройте [http://localhost:3000](http://localhost:3000)

## Сборка для продакшена

Проект использует статический экспорт, поэтому `npm run build` генерирует статические файлы в каталог `out/`:

```bash
npm run build
```

Содержимое `out/` загружается на любой статический хостинг.

> **Безопасность:** т.к. это статический экспорт, HTTP-заголовки безопасности
> (`X-Frame-Options`, `Strict-Transport-Security`, `Permissions-Policy` и др.)
> нужно настраивать на уровне хостинга (`.htaccess`, конфиг Nginx или `vercel.json`),
> а не через `next.config.js`.

## Особенности

- Полная адаптивность (мобильные, планшеты, десктоп)
- Многоязычность (русский/английский) с переключением в реальном времени и синхронизацией атрибута `lang`
- CSS-анимации и плавные переходы
- SEO-оптимизация: уникальные метаданные для каждой страницы, Open Graph, canonical
- Темная тема с неоновыми акцентами
